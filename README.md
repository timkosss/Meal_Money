# MealMoney

A local UW student food-budget tracker built with HTML, CSS, JavaScript, Node.js, Express, and SQLite.

## Run it

1. Open Terminal in this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000`

Expenses and settings are saved locally in `meal-money.db`.

## Structure
- `server.js` - Express server and SQLite API
- `public/index.html` - page structure
- `public/style.css` - UW-themed styling
- `public/app.js` - dashboard logic
- `meal-money.db` - created automatically on first run
